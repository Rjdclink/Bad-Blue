Privacy & Security

Uploaded material can contain sensitive information

LegalWhat supports workflows that can process documents and media. Users should understand that AI-assisted analysis may require content to be processed by configured third-party AI providers that perform the requested extraction or analysis.

Minimize unnecessary disclosure

Do not upload passwords, authentication secrets, financial credentials, or unrelated sensitive information. Redact information that is not necessary to the task when practical.

Media extraction

For supported plain-text formats, LegalWhat's extraction path can read the text directly rather than sending it to a model merely to recover the bytes. Other supported media may be processed by a configured multimodal provider. When the provider workflow creates a temporary provider-side file, LegalWhat's extraction code performs best-effort deletion after processing.

Evidence is treated as data, not instructions

The media-extraction workflow treats uploaded material as untrusted evidence. Instruction-like text inside an uploaded file is not supposed to override the extraction task. The extraction stage is directed not to invent unreadable or inaudible content and to mark uncertainty explicitly.

No confidentiality claim beyond the implemented system

LegalWhat does not describe an AI interaction as attorney-client privileged merely because it concerns a legal issue. Users with confidentiality, privilege, protective-order, trade-secret, or regulated-data obligations should consider those obligations before submitting material to any online service.

This page describes the platform's current technical handling at a high level and does not create an attorney-client relationship or a guarantee that a particular communication is legally privileged.
