# Nix-Gen

Nix-Gen is an additive global opportunity-allocation layer for CryptoCrawler.

Current foundation rules:

- It consumes canonical measured economics; it never creates economics.
- It consumes existing authoritative execution/settlement capability; it never grants execution authority.
- It may compare feasible combinations of already-eligible strategy bids under shared scarce-resource budgets.
- Its output is advisory until a separately verified canonical integration explicitly consumes its ordering.
- Governance, Profit Ladder, resource ownership, nonce/rate safety, kill switch, settlement and terminal learning remain authoritative elsewhere.
- Each implementation slice must remain useful without requiring a later slice.

Research principles applied to the design include bounded real-time optimization, explicit resource constraints, dual/scarcity-aware resource allocation, continuous replanning, robust uncertainty handling, and deterministic fallbacks.
