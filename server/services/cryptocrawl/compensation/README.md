## 🚀 Quick Start

### Basic Usage

```typescript
import compensationSystem from './compensation';

// Start the entire system with hourly payouts
await compensationSystem.start('0xYourWalletAddress', {
  token: 'ETH',
  chain: 'ethereum',
  enableHourlyPayouts: true,
});

// System is now earning and paying out automatically!
```

### Record Revenue Streams

```typescript
import { 
  computationalGrid, 
  flashEngineRevenue, 
  crawlerBounty, 
  triBeamBroadcast 
} from './compensation';

// Record CPU/GPU task completion
await computationalGrid.registerTask('gpu', 1000, 'ethereum');

// Record flash engine profit
await flashEngineRevenue.recordProfit(
  'arbitrage',
  '0.005',  // 0.005 ETH
  150,      // 150ms execution time
  true      // reversible
);

// Record crawler bounty
await crawlerBounty.claimTask('crawler-001');
await crawlerBounty.completeTask('crawler-001', '0.001');

// Record tri-beam broadcasting
await triBeamBroadcast.registerNode('node-001', 10);
```

### Manual Payout Trigger

```typescript
import { payoutScheduler } from './compensation';

// Trigger immediate payout (for testing)
const transaction = await payoutScheduler.triggerPayout();
console.log('Payout transaction:', transaction);
```

### Get Statistics

```typescript
import compensationSystem from './compensation';

const stats = compensationSystem.getStats();

console.log('Engine state:', stats.engine);
```
