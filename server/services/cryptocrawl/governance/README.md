**Duration:** Days 1-7  
**Execution:** ❌ None (Advisory/Testing)  
**Daily Target:** $0  
**Capital:** $1,000 (testing only)

- Signal reasoning and strategy optimization
- Arbitrage path discovery
- Monte Carlo validation
- No execution authority

**Exit Criteria:**
- 100+ simulated trades
- 70%+ success rate
- Sharpe ratio > 1.5
- 3+ days stability

## 🔒 Global Rules (Apply to ALL Stages)

1. **No Assumptions** - No silent expansion, all changes explicit
2. **No Autonomous Evolution** - Evolution Lock ON unless explicitly lifted
3. **Execution Requires Authorization** - Explicit unpause or approval
4. **Pause Semantics Absolute** - Cannot override pause state
5. **Ambiguity → Ask-and-Wait** - No guessing, request clarification
6. **Advancement Requires UNPAUSE** - Human authorization mandatory

## 🚀 Quick Start

### Installation

```bash
cd /workspace
npm install

# Apply database migration
psql $DATABASE_URL < db/migrations/eden_swarm_migration.sql
```

### Initialize

```typescript
import { initializeGovernance } from './server/services/cryptocrawl/governance';

await initializeGovernance();
```

### Start Monitoring

```typescript
import { monitoringDashboard } from './server/services/cryptocrawl/governance/monitoring-dashboard';

monitoringDashboard.start(5000); // Update every 5 seconds
```

### UNPAUSE System

```typescript
import { composer } from './server/services/cryptocrawl/governance/composer-interface';

await composer.unpause(
  'your-operator-id',
  {
    allowedChains: ['polygon', 'arbitrum'],
    maxPairs: 10,
    maxVenues: 3,
    maxDailyProfit: 500,
  },
  86400000 // 24 hours
);
```
