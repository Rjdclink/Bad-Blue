# Seven-Stage Three-Pass Optimization Framework

## Overview

A systematic optimization framework that enhances each of the seven crawlers through **three progressive passes**, with each pass increasing optimization power exponentially (2x, 4x, 8x).

## Philosophy

### Power Scaling (2^n)
- **Pass 1**: 2x power multiplier - Foundation optimization
- **Pass 2**: 4x power multiplier - Compound enhancement  
- **Pass 3**: 8x power multiplier - Maximum amplification

### Attribute Prioritization
Each crawler has **3 top attributes** optimized in **descending order of importance**:
1. **Primary Attribute** - Highest impact, receives most optimization focus
2. **Secondary Attribute** - Support capability, moderate optimization
3. **Tertiary Attribute** - Enabling feature, baseline optimization

### Intent Inference
The system is designed to infer and match intended operational requirements with extreme accuracy, adapting optimizations to discovered patterns and user objectives.

## Usage

### Execute All Stages Sequentially

```typescript
import { SevenStageOptimizationOrchestrator } from './SevenStageOptimization';

const orchestrator = new SevenStageOptimizationOrchestrator();

// Listen to events
orchestrator.on('pass:complete', ({ stage, pass, improvements }) => {
  console.log(`Stage ${stage}, Pass ${pass} complete:`, improvements);
});

orchestrator.on('optimization:complete', ({ stages, profiles, totalImprovement }) => {
  console.log(`Total system improvement: ${totalImprovement.toFixed(2)}x`);
});

// Execute all 7 stages, 3 passes each
const results = await orchestrator.executeAllStages();

console.log('Optimization Results:');
console.log(`- Total improvement factor: ${results.totalImprovement}x`);
console.log(`- Stages completed: ${results.stages.length}`);
console.log(`- Crawler profiles optimized: ${results.profiles.length}`);

// View individual stage results
results.stages.forEach(stage => {
  console.log(`\n${stage.crawlerName}:`);
  console.log(`  Overall improvement: ${stage.overallImprovement}x`);
  console.log(`  Top attributes: ${stage.topAttributes.join(', ')}`);
  
  stage.passes.forEach(pass => {
    console.log(`  Pass ${pass.passNumber} (${pass.powerMultiplier}x):`, pass.improvements);
  });
});
```

### Execute Individual Stage

```typescript
const orchestrator = new SevenStageOptimizationOrchestrator();

// Execute only Stage 3 (The Chewer)
const chewerStage = await orchestrator.executeStage(3);

console.log('Chewer optimization complete:');
console.log(`Overall improvement: ${chewerStage.overallImprovement}x`);

// Get optimized profile
const chewerProfile = orchestrator.getProfile(3);
console.log('Optimized metrics:', chewerProfile.optimizedMetrics);
console.log('Baseline metrics:', chewerProfile.baselineMetrics);
console.log('Improvement factor:', chewerProfile.totalImprovementFactor);
```

## Implementation Details

### Pass Execution Flow

```
For each crawler (7 stages):
  For each pass (3 passes):
    1. Initialize pass with power multiplier (2^passNumber)
    2. Apply attribute optimizations in descending priority:
       a. Primary attribute (highest weight)
       b. Secondary attribute (moderate weight)
       c. Tertiary attribute (baseline weight)
    3. Calculate improvement factors
    4. Update optimized metrics
    5. Emit pass:complete event
  
  Calculate overall stage improvement
  Emit stage:complete
  
Calculate total system improvement
Emit optimization:complete
```
