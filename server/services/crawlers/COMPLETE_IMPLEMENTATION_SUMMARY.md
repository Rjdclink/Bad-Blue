### Seven Crawlers

Each crawler has a dimensional constraint (cannot see one critical dimension):

1. **The Mirror** - Cannot see: Intent
2. **The Key** - Cannot see: Time
3. **The Chewer** - Cannot see: Identity
4. **The Computational** - Cannot see: Configuration
5. **The USC** - Cannot see: Meaning
6. **The Woo** - Cannot see: Incentives
7. **The Silence** - Has: Hyper-Awareness (no constraints)

**Result**: Truth emerges between crawlers, never inside them.

### Cain: The Overseer

**Roles**:
- Bus driver (lifecycle coordinator)
- Hand holder (safe operation)
- Alarm system (divergence detector)
- Failsafe switch (termination authority)

**Epistemic Demand-Driven Starburst**:
```
RP = f(ESA × EG × CR) + ED
Final = min(RP, System Capacity)
```

Where:
- **ESA**: Epistemic Surface Area (how many unknowns?)
- **EG**: Entropy Gradient (how unstable?)
- **CR**: Compression Resistance (how hard to simplify?)
- **ED**: Evolutionary Debt (what was missed?)

**Failsafe Mechanism** (Hard Rule):
- Embedded in each disciple before starburst
- `discipleAware: false` - ALWAYS (no exceptions)
- Can erase 1 to ALL crawlers
- NO WORKAROUNDS - computationally enforced
- Any divergence → terminate ALL → return to Eden

### Integration Example

```typescript
import { 
  SixCrawlerInitiative, 
  SevenStageOptimizationOrchestrator,
  Cain,
  Reaper 
} from './server/services/crawlers';

// Optimize crawlers
const optimizer = new SevenStageOptimizationOrchestrator();
const optimized = await optimizer.executeAllStages(); // 64x improvement

// Initialize oversight
const cain = new Cain(1000000);
const reaper = new Reaper();

// Scan Eden
const scan = await cain.scanEden(environment);

// Initialize initiative
const initiative = new SixCrawlerInitiative({
  authorizedMode: true,
  enableNearMissArchive: true,
  enableBlindSpotDetection: true,
  enableConsentAmplification: true,
});

await initiative.start();

// Leave Eden with failsafes
const crawlers = [/* seven crawlers */];
await cain.leaveEden(crawlers);

// Execute operation
const results = await initiative.executeOperation({...});

// Evaluate health
const reaperAction = await reaper.evaluate({
  crawlers,
  metrics: initiative.getStatus().crawlers,
  history: results.insights,
  timeWindow: 60000,
});

// Watch for divergence
const diverged = await cain.watchForDivergence(metrics);

// Handle results
if (diverged || reaperAction.action !== 'none') {
  await cain.returnToEden('cycle_complete');
}
```
